02 问题与修复

问题原因修复
私有文件进入发布包高风险Git 忽略规则隐藏 .pem、.env 等文件；public 与迁移目录被递归打包。打包前拒绝额外文件、敏感文件名和符号链接；从指定提交建立私有目录，按清单归档，并读回核对路径、类型、大小与摘要。
构建依赖来源未验证高风险直接执行工作区 node_modules 中的构建工具，未强制重装锁定依赖。隔离目录先运行有时限的 npm ci，再构建和校验。原工作区的依赖树不进入发布链；任何步骤失败均停止归档。
生成内容冒充教材中风险对话仅检查 JSON 和文本长度，缺少结构化任务已有的教材声明校验。复用服务端声明校验，覆盖正文和操作按钮；服务端生成来源信息，页面及恢复的历史明确显示“AI 生成内容 · 教材原文未核验”。
自动日志保存私人文本中风险口语、追问、个人文章与听写将自由文本或私人标识写入事件和每日摘要。客户端与服务端共享结构化事实规则，屏蔽个人文章记录；迁移清理自动文本与派生摘要，保留主动编辑，清空日志时拦截迟到写入。
  • 补查同类入口：听写标题可带入私人文章句子，已纳入共享日志规则；账号、临时会话与隐私版本隔离继续保留。
  • 精简检索热路径：复用不可变词库的规范化来源信息，只收集有界排名结果，避免重复规范化和收集全部匹配结果。
