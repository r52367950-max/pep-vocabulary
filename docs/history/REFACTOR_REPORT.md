## 学习逻辑

1. 教材与单元必须命中同一条来源记录，防止跨册同名单元串词。暂停词不进入自动队列，专名默认不占日常额度。
2. 先复习到期词，再按剩余时间安排新词。只复习模式不混入新词；新词额度按今天实际接触的词扣减。
3. 听写不提前显示单词或释义；主动使用提示后限制评分。大小写、空白和规范化字符可兼容，不能靠删除全部标点绕过拼写检查。
4. 错误、使用提示及“没记住”评分会安排本轮再次回忆。每词最多一次巩固，首次作答与重复作答分开统计。
5. 先在 IndexedDB 事务中保存词卡和事件，再推进界面。撤销生成关联事件；刷新按已提交事件修复检查点，防止重复调度或丢失撤销。检查点有效期 24 小时。
6. 等详情读取完成或明确失败后固定题目；缺少有效例句时说明实际降级题型。字典英文定义不冒充语境句。

内部保留 15 个兼容题型标识，不代表每个词都有 15 种高质量题。主要入口为回忆、拼写、听写和语境；旧高级题型缺少证据时明确降级。

## 内容与词库

新增 **6 篇原创短文、12 道理解题、36 个文章目标词、48 条原创例句**，覆盖校园、生物、旅行、环境、科技和文学生活。短文各 103–114 个英文词，有译文及答案解释，标注“词迹原创 · 非教材原文”。目标词可查看并练习。理解题选择暂不进入长期 FSRS 或跨设备同步。

保留 4,681 个稳定词条及收藏笔记。修复加载显示时 32 个词中 `NAmE` 被转成 `ŋɑmE` 的问题；原文只给缩略美式音标时不推造完整形式。构建器改为先分离地区标记，再转换音标字体。当前环境没有完整教材来源缓存，因此没有重新发布全库数据，原始候选与证据保持保留。

自动审计通过，但原有 **333 个词条缺开放英文简义、153 个词条音标字段不完整、7 个单元有未解析记录**仍需内容审核。新增例句只覆盖有限目标词，当前版本不是全库教材与发音的人工终审。

## 安全与后端

- 同源请求、服务端身份隔离、D1 原子限额与 revision 比较更新；新增同步账号绑定，账号变化或其他设备更新时拒绝静默覆盖。
- 新保存的 AI 密钥采用 AES-GCM v2，绑定账号、服务商与目标地址；旧密钥再次保存时升级。接口和用户备份不返回密钥。
- 限制请求与上游响应字节及读取时间；取消流阻塞也不会拖住超时。导入验证日期、指标、调度状态、撤销关联。
- Service Worker 按构建指纹分版本，完整 shell 保存失败不会替换旧版本。API、身份请求、RSC 不缓存；确认所有词库分片写入当前缓存后才提示离线准备成功。
- 页面加载失败有恢复提示，模型不可用不影响本机学习。

云端目前是手动整份快照备份，不是自动增量同步；本地也没有按账号分区。公开部署依赖受信任网关，URL 校验不等于完整 DNS 重绑定防御。后续 outbox、幂等事件、游标拉取、词卡并发、删除传播方案见 [BACKEND_ARCHITECTURE.md](../BACKEND_ARCHITECTURE.md)，均明确标注尚未实现。

## 发布兼容修复

首次新版本发布遇到旧实例数据库已存在 `ai_rate_limits` 的情况。第 14 版迁移返回 `table ai_rate_limits already exists`，发布未完成。将三份初始迁移中的建表语句改为 `CREATE TABLE IF NOT EXISTS`，不删除、重建或重置已有数据。

在临时 D1 中分别验证空库启动、只存在旧限额表且含数据的启动，以及完整快照与加密配置已经保存后的重复迁移。重复执行必须保留请求计数、快照 revision / payload 和配置密钥。
