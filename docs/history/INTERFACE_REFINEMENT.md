## 字体与文案

- 以 `-apple-system` / `BlinkMacSystemFont` 调用苹果平台系统字，显示与界面字体分别声明，保留本地 SF Pro 家族回退。中文由系统及苹方等中文家族覆盖。
- 移除中文标题的负字距、650 等不稳定字重；统一 400 / 500 / 600 字重层级。常规字号改用 rem，辅助文字最低 12px，词条释义与主要操作提高字号。
- 没有打包或远程分发 Apple 字体。Windows / Android / Linux 会使用自身可用的后备字体；没有宣称跨平台都能显示 SF Pro。本轮也没有在实际 Apple 硬件上确认渲染。
- 删除“从认识，到自然表达”“一点一滴，都算数”等宣传式文案，使用真实的计划词数、学习状态和直接的动作名称。

参考：[Apple Fonts](https://developer.apple.com/fonts/) 的系统字体、光学字号及许可说明；[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion)；[Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)。使用了 frontend-design、web-design-guidelines、react-best-practices 技能。

## 今日与词库

今日页先展示当前教材与进度，随后为紧凑的每日计划。蓝色书页保留为次要内容图，听写、阅读改成直接入口。手机上无需滚过大幅封面再寻找开始按钮。

词库将搜索、搜索范围与筛选组成统一工具栏，筛选按需展开；保留教材、单元、学习状态、收藏、选择、详情、听写、练习和 CSV 导出。桌面增加轻量列标题，手机使用两行词条与可读的状态标签。

主要入口新增 7 个原创功能 SVG 图标。统一 28 单位网格、圆角笔画与层级填色，侧栏显示带细微材质的彩色图标，手机标签使用单色状态。它们不是 Apple SF Symbols 资源，无新增图标或动画依赖。

## 动画

| 交互 | 时长与处理 |
| --- | --- |
| 页面切换 | 180ms 淡入，不位移页面内容 |
| 搜索范围切换 | 260ms 选中底板滑动 |
| 手机标签切换 | 300ms 底板滑动，渐缓停止 |
| 按钮轻按 | 90ms 压缩至 97.5%，220ms 归位 |
| 词条详情打开 | 260ms，8px 位移与小幅缩放 |
| 答案反馈 | 200ms，4px 位移与淡入 |
| 练习进度 | 300ms scaleX，替代 width 动画 |

只使用 CSS 与现有 React 状态。无自动循环、滚动入场、逐行级联或阻塞输入的等待。`prefers-reduced-motion` 禁用动画、过渡和按压缩放，保留即时状态反馈。移动标签与搜索范围的过渡可以中途改向。
