# 视觉路线与选择

> 历史记录：保留当时的设计、过程与验证证据。文中的当前状态、下一步、分工、工具限制和测试安排仅适用于当时轮次；现行开发约定见 [AGENTS.md](../../AGENTS.md)。文内代码路径仍以仓库根目录为基准。

## A 安静书桌（采用）

单列学习、侧栏导航、宽留白和清晰的目标词中心；中文用 Noto Sans SC，拉丁/IPA 用 Noto Sans，长解释以 Source Serif 4 补充阅读节奏。适合 20–30 分钟持续学习，减少卡片堆叠和奖励噪声。

## B 编辑索引（词库页采用）

三栏高密度结构：左侧筛选、中部词条索引、右侧详情与来源。适合桌面/iPad 快速查找、跨册对照和批量浏览；手机降为顺序单列。

## C 语境路径（分析页局部采用）

以时间趋势、能力条和短任务建议构成轻量路径，强调“下一步为什么”。不做复杂关系图，不让分析页退化成签到数字。

最终设计以 A 为主、B/C 局部融合。浅色背景 `#F4F7F5`、主文字 `#142A2A`、强调 `#2F6F6A`；深色使用等价对比。层级由网格、比例、字重和规则线构成，少用阴影/渐变；焦点环、键盘、触控、减少动效和非颜色正误反馈均在 CSS/组件中实现。
