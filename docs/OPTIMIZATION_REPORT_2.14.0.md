# 2.14.0 体验与性能优化报告

基线：2.13.1（`3436a17`）。测试为本地生产构建，由 workerd 提供；数据为本次实验结果。[两页图文版](OPTIMIZATION_REPORT_2.14.0.pdf)。

## 重点结果

- 在首页就绪后等待 4 秒再操作，9 个入口首次打开耗时的中位数由 **401 ms 降至 187 ms**（各入口三次测量的中位数，再取九项中位数）。
- 首页阻塞样式体积由 **31,643 B 降至 17,571 B gzip**，减少 **44%**；首次预热或打开功能时另加载 15,371 B gzip 的功能样式。
- 口语背景图由 **1,801,292 B 降至 29,592 B**，减少 **98%**。
- 词库检索复用已规范化的字段与选定范围，降低重复计算；搜索结果语义保持一致。

## 首次打开

无头 Chromium、1280×800、4× CPU 节流、本地服务；每个入口采用新浏览器上下文，首页就绪后等待 4 秒，再测量点击至目标内容绘制。前后各 3 次，表中为中位数。实际体验随设备、网络、缓存及预热时机变化。

| 入口 | 2.13.1 | 2.14.0 |
| --- | ---: | ---: |
| 词库 | 401 ms | 196 ms |
| 阅读 | 419 ms | 222 ms |
| 学习记录 | 365 ms | 187 ms |
| 开始学习 | 501 ms | 219 ms |
| 设置 | 400 ms | 116 ms |
| 单词详情 | 407 ms | 160 ms |
| 词汇练习 | 352 ms | 115 ms |
| 口语对话 | 421 ms | 240 ms |
| 写作练习 | 378 ms | 79 ms |

首页数据就绪后等待 1.5 秒，再按空闲时段逐个预热常用功能；导航的指针与键盘焦点也可提前触发加载。已预热组件直接渲染，较慢加载时继续提供等待反馈。预热会在后台请求功能代码和样式，带来额外网络与解析开销；离线资源清单包含拆出的功能样式。

## 界面细节

- 首页插画的日月避开标题区域；学习卡片的教材来源按片段换行。
- 单词来源标签加强层次；学习记录的四列指标允许收缩；统计标题字号调整。
- 等待提示延迟淡入，短暂切换更平稳；保留系统减少动效设置。

## 验证

- `npm run typecheck`、`npm run test:unit`（515 项）、`npm run build` 与 `npm run test:runtime` 通过。
- 桌面与手机视口、浅色与深色界面巡检完成；脚本记录的页面异常为 0。
- `npm run lint` 报告 6 个错误和 6 个警告，位于本次未修改的语音及学习日志文件。
- 本地 Worker 测试使用临时 D1，真实认证网关、真实 AI 服务和物理设备留待部署环境验证。
