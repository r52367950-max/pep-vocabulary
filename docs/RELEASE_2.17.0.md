# 词迹 2.17.0

2026-11-06，基于 main `b224f1c`。

## 多设备合并

- 上传时云端已有其他设备的新快照（本机关联的 revision 落后、本机尚未关联，或上传得到 `409 / revision-conflict`），界面请用户确认合并，不再只能二选一覆盖。
- 作答按 `eventId` 取并集。一个词只在一侧有新作答时沿用那一侧；两侧都作答过时，以服务端已确认的云端历史为基准，在其后重新计算本机作答的调度，保留每条作答的 ID 与作答证据。本机撤销随原作答重放。
- 笔记、收藏、暂停、设置、作文元数据取较晚修改的一侧，作文版本按 ID 合并。
- 合并结果须通过完整备份校验；云端接受后才替换本机数据，替换时在同一事务里确认本机自导出后没有新记录，否则保留本机数据并提示再次上传。再次合并能识别云端已重算的同一条作答，不重复计数。
- 本页发起的恢复、合并或清空完成后显示各自的结果，不再被“本机学习数据已替换”的通用提示盖住；其他页面替换数据时仍显示该提示。

## 性能

- `public/data/v1/index.json` 改为 `pep-lexicon-index/2` 行编码（共享册次表、四个发布标记合成位字段）：2,313,458 → 759,461 字节，gzip 295 KB → 241 KB。Chromium 中解析加解码 6.7 → 4.3 ms，4 倍 CPU 降速下 26.2 → 16.3 ms（9 次中位数，`artifacts/qa/2.17.0/lexicon-index-parse.json`）。
- 编码 / 解码只有 `lib/lexicon-index-codec.mjs` 一份实现，客户端、三个 Worker 证据读取点、发布构建与校验共用；客户端仍能读取旧版 Service Worker 缓存里的对象数组。发布校验要求行编码，并逐条与详情分片投影比较。

## AI 额度

- 每日请求次数（含连接测试）改在北京时间 0 点重置，与 token 预算、语音时长一致；用完时说明重置时间。
- 服务商在生成前明确拒绝（重定向，或除 408 外的 4xx）时退回本次预留的输出额度，提示词估算仍计入；超时、5xx、断流仍保留全部预留。

## 界面

- 学习记录：还没有作答时显示一张引导卡和“开始今天的学习”（有未完成的一轮先继续），不再显示空柱状图和七行“0 词”。
- 今日页：桌面版教材与单元选择框按所选文字定宽（Chromium 的 `field-sizing`），箭头紧贴文字；手机上“约 10 分钟”放在卡片底色胶囊上，各时段插画上对比度由 1.20–2.60 提升到至少 5.18:1。
- 纸上听写的“识别文字”按钮改由状态控制，仍保持一张照片最多付费识别一次；听写面板的推荐计划在渲染期应用，并通过 effect event 保证每个上下文最多自动请求一次。两个听写组件的超长单行 JSX 已拆分。
