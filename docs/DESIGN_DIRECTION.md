# 词迹 2.0：学习内容与清晰的操作

本方案替代纸页风格及随后白灰统计面板两稿。用户要求全面重建，并明确参考 Apple Design；本次采用 Apple Books / Music 的内容组织方式、Translate 的宽屏侧栏与单任务结构，而不是仅替换配色。实际观察材料与版本边界见 [APPLE_PRODUCT_RESEARCH.md](APPLE_PRODUCT_RESEARCH.md)。

## 产品结构

- 桌面：固定轻灰侧栏，上方为今日、词库、阅读，下方为记录、设置。搜索直接进入词库。主区保留一个清楚的标题，没有第二层全局导航。
- 今日：教材、单元与真实进度在计划上方；计划直接展示本轮词数、复习／新词组成、用时和开始／继续操作。封面缩小，听写与阅读使用紧凑的图标入口。
- 学习：进入独立全屏，隐藏应用导航。主词／语境为视觉中心；答案先回忆后揭示，评分随后出现。操作区保持稳定位置，听写按钮反馈真实语音播放状态。
- 词库：搜索、教材与学习状态筛选、简洁词表。点击“选择”才出现复选框；词条详情、收藏、练习和导出保留。
- 阅读：主封面与不等权目录。正文收敛到约 680px，译文与课内词按需展开，目标词可进入练习。
- 手机：单列内容、上下重排的封面、底部悬浮标签导航；安全区域、焦点、减弱动态和强制颜色模式有对应处理。

## 视觉语言

系统无衬线字体，无远程字体下载、无 Apple 商标或 SF Symbols 资源。中性背景与系统蓝承担界面秩序；封面负责色彩与情绪。主要入口采用原创 SVG 功能图标，其他工具图标继续使用 Lucide。图标统一光学网格与双层填色，侧栏用彩色小图标，手机标签用单色选中态。阴影只用于浮层、图标与分段选项；透明与模糊只用于导航和固定操作层。

主封面是蓝封皮、白色弧形书页的精密静物；交流与自然封面沿用纸张、浅色背景、softbox 光线和清楚的单一主体。画面不包含文字，所有标题、按钮、状态均由可访问 HTML 排版。三张图片使用本地 WebP，没有外部图片依赖；为非关键图片启用延迟加载和固定尺寸。

布局使用 8px 左右的间距节奏、受控的内容宽度、清楚的字号差异。页面标题约 30–34px；学习计划标题约 26–34px；中英文界面使用系统字体，中文标题去除负字距，主内容为 16px，常用标签 14–16px，辅助文字 12–13px，使用 rem 跟随用户字号。颜色与文字一起表达正确、错误、到期状态，不以颜色作为唯一提示。

2026-09-15 的具体实现、字体边界与动效时序见 [INTERFACE_REFINEMENT.md](INTERFACE_REFINEMENT.md)。

## 验证要求

逐页观察桌面、390px 手机、较窄手机与深色模式，检查实际文字和图片加载。验证焦点、词库选择、详情关闭、听写隐藏与错误反馈、刷新恢复、阅读理解反馈。托管使用生产构建和真实 worker 运行验证；最终截图及结果在 [REFACTOR_REPORT.md](REFACTOR_REPORT.md)。
