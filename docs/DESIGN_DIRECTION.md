# 词迹 2.0 设计方向

面向使用 iPad 和手机的人教版高中英语学习者。首要任务是用几分钟完成一轮可追踪的回忆、拼写或听写，并在短文中练习用词。

采用 frontend-design 技能（Anthropic 官方公开仓库，2026-09-15读取）的两遍工作法。初稿审视后，舍去旧版控制台式常驻技术面板、多层边框与全大写标签。首页保留一个主要学习按钮，单词页签作为唯一醒目的视觉元素；导航只承担定位，不展示服务器和调度细节。

- 色彩：纸白 #F7FAFA、墨蓝 #203C51、湖蓝 #567AAB、浅蓝 #E9F0F7、叶绿 #27776A、浅金 #CEAC74。
- 字体：中文使用设备系统字体，英文单词与短文使用 Source Serif 4 的 latin 子集。正文保持短行，单词可自动换行。
- 布局：桌面左导航，iPad紧凑导航，手机底部五项导航；学习时全屏聚焦单题。首页为主学习区、今日记录、三项练习入口与真实教材进度。
- 交互：大触控区、可见焦点、原生弹窗焦点管理、尊重减少动效设置。所有数字来自学习数据，不预填成绩与打卡记录。

公开产品研究：实际查看墨墨与不背的官方商店截图、Anki官方学习说明图；扇贝和Quizlet仅核实公开功能文案。借鉴渐进揭示、复习优先与语境学习；代码、图形、短文均原创，不复制竞品资产或受保护课文。
