# 词迹 2.18.0

2026-11-08。改善词库、写作和备份的边界状态，减少重复搜索及异常 AI 回复的处理开销。

## 改动

| 范围 | 结果 |
| --- | --- |
| 词库性能 | 文本匹配与学习状态筛选分开缓存，收藏、复习更新复用已有搜索结果。 |
| 跨搜索选词 | 所选词跨搜索和筛选保留；数量、清除入口和练习队列始终包含全部所选词，避免隐藏选择占用 80 词名额却无法操作。 |
| 词库加载 | 索引与详情请求有 30 秒截止时间，覆盖响应正文读取；失败清理共享请求，重试可以恢复。 |
| 缓存异常 | Service Worker 打开或读取缓存失败时仍尝试网络，保持在线学习可用；私有 API、认证与 RSC 缓存排除规则保留。 |
| AI 解析 | 助手和文章分类的代码围栏剥离改为线性操作，长度限制在解析前执行，避免合法 JSON 中的大量空白触发正则二次回溯。 |
| 连接取消 | 连接测试将取消信号传给上游探测，取消后停止后续候选端点请求。 |
| 云备份 | 同一事务内保护 revision 与对应合并基准，忽略同账号迟到的旧确认；不同账号保留独立版本序列。 |
| 写作 | 读取失败显示可重试错误；保存失败显示“尚未保存，请复制保留文字”；删除冲突后刷新列表核对最新状态。 |

词条 ID、备份 schema、历史迁移和站点访问范围保持兼容。本次没有新增数据库迁移。

## 验证

- 完整单元与回归：581 项通过，无失败或跳过。
- TypeScript、ESLint、词库数据审计、生产构建及产物校验通过。
- 本地 workerd/Miniflare 与临时 D1 验证通过，覆盖鉴权、配置、备份、运行时接口及数据库重放保存已有数据。
- `npm run audit:prod`：0 个已知生产依赖漏洞。
- 独立代码复核覆盖请求超时、缓存回退、AI 解析/取消、备份事务和写作错误状态。
- 独立 Sol high 浏览器回归：在本地 Chromium 临时浏览器上下文验证跨搜索保留 80 词、拒绝第 81 词、零结果下仍能清除/练习；注入本地写作读取和保存故障，确认重试恢复与失败文案。脚本和精选截图见 `artifacts/qa/2.18.0/`。

AI 解析微基准：60,000 个内部空白的合法 JSON 从约 2,587 ms 降至约 0.062 ms；该结果只衡量本地解析函数。回归以独立线程看门狗验证 240,000 空白输入，防止同步卡顿使常规测试超时失效。词库性能收益来自状态更新时消除重复全文扫描，没有宣称全站速度倍数。

## 验证边界

本次未调用付费 AI，未修改用户生产记录。模型质量、真实服务商和物理设备行为未纳入自动化验收。安全结论来自源码审查与行为回归；完整 Codex Security 扫描资源不可用。

专用 computer-use 接口未提供，本轮浏览器操作使用 Playwright 驱动实际 Chromium；窄屏检查为模拟视口，未替代物理 iPad/Safari 测试。

数据审计仍列出既有的 333 个英文释义缺口、153 个音标不完整词条及 7 个含未解析字段的单元；本次没有无来源补写词库内容。
