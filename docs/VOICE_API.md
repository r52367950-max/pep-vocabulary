# 词迹 2.7：听说练习与学习记忆

## 使用

登录原站点，打开「设置 → AI 接口 → 使用 OpenAI 推荐配置」，填入 API Key 后保存。文字模型默认 `gpt-6.1-terra`，可改为 `gpt-6.1-sol`；实时口语固定 `gpt-live-1`，AI 听写固定 `gpt-audio-1.5`。模型可用性取决于该 API 项目的权限和余额，保存配置不表示已调用验证。

首页「开始口语」「词句听写」直接进入对应页面，侧栏保留「口语与听写」。口语默认日常生活 / B1 / 10 分钟，可以选择六个主题、B1/B2/C1 和 5/10/15/20 分钟。设备听写不需要 API Key 或麦克风；已安装的本地英语声音可离线，系统其他声音可能仍需联网。

## 接入选择

- 文字：官方 OpenAI 地址使用 Responses API；兼容服务保留 Chat Completions，已有 DeepSeek 配置不会自动更换。
- 实时语音：浏览器通过原生 WebRTC 传输音频，服务端使用已加密保存的 Key 创建 Live 会话并返回 SDP。长期 Key 不下发浏览器，不写入前端持久存储或学习备份。
- 会话关闭：浏览器发送 `session.close`；服务端通过 Live sideband WebSocket 发出相同命令，并等待 `session.closed`。刷新后可以关闭所属账号遗留的会话，不允许跨账号关闭。服务端在返回 SDP 前持久化截止时间和加密关闭凭据；Durable Object 闹钟到期后关闭会话，临时失败时保留单活锁并有上限地退避重试。删除或更换 AI 配置不影响已创建会话的关闭；已吊销的 Key 或不可解密的快照会终止本地管理并释放锁，但不会被描述为服务商已确认关闭。
- 听写：用户明确选择 AI 语音并点击播放后才请求音频。服务端按归一化词元和字符量保守预留时长，核对返回转录与目标原文，并验证 WAV；可安全解析音频时长时只追加超出预留的秒数，不退还预留。重播和 0.8 倍播放复用本页音频缓存。
- 反馈：结束后可先修正转写，再请求文字反馈。最多两条改进，只能引用学习者实际发言；不从转写推断发音分数。

| 站点接口 | 用途 |
| --- | --- |
| GET `/api/voice/status` | 配置状态、应用秒数预算、尚未确认结束的会话 |
| POST `/api/voice/session` | 验证主题、难度、时长和 SDP，创建会话 |
| POST `/api/voice/close` | 验证会话归属并确认远端结束 |
| POST `/api/voice/speech` | 生成指定词语或句子的听写音频 |
| POST `/api/voice/feedback` | 根据可修正的对话文字生成反馈 |
| GET / PUT `/api/voice/memory` | 账号隔离的学习记忆；保存携带 revision，冲突返回 409 |
| POST `/api/voice/recommend` | 按学习记忆和用户选择生成最多三组可编辑推荐 |
| POST `/api/voice/discuss` | 围绕本次转写继续文字复盘，返回可选择保存的记忆建议 |

所有接口复用站点身份、同源校验、服务端加密配置和用量控制。语音以 D1 原子预留每日 3600 秒，提前结束不退还应用预留；文字 token 另行预留。静音和思考暂停仍会产生语音费用。每个 Live 会话的服务端截止时间从开始预留预算时计算，浏览器倒计时仅辅助显示。闹钟调度、服务商排空和网络故障仍可能使实际终止稍晚，应用预算不等于服务商硬账单上限。创建请求若在拿到 session ID 前超时，无法确认上游是否创建，故不自动重试。

最近 12 次口语转写、反馈与复盘对话、最多 300 条听写记录仅存当前浏览器，不包含录音，不进入现有学习备份；可从各自页面删除。每次最多保留最近 150 段转写，长对话的反馈最多使用最近 18,000 字符。

全局清空本机数据会删除所有账号的本机口语、听写记录和学习画像授权，并阻止其他标签页回写清空前的记录。安全持久化使用 Web Locks；不支持它的浏览器仍可练习、读取和清除已有记录，但不保存新的敏感练习记录或画像授权。

## 研究与取舍

核对日期：2026-10-29。实现依据 OpenAI 的 [WebRTC 指南](https://developers.openai.com/api/docs/guides/voice-webrtc)、[Live 会话管理](https://developers.openai.com/api/docs/guides/live-conversations)、[sideband 控制](https://developers.openai.com/api/docs/guides/voice-server-controls?api=live)、[音频 Chat Completions](https://developers.openai.com/api/docs/guides/audio-chat-completions)和 [Responses 文本生成](https://developers.openai.com/api/docs/guides/text?api-mode=responses)。没有把旧 Realtime 事件名混用到 Live 协议。

也考察了 [LiTy](https://github.com/voidism/LiTy) 的语音/文字语言伙伴思路、[SpeakAlong](https://github.com/r4yg/speakalong) 的重复播放、隐藏文本、变速与本机学习记录。本次采用短任务、可隐藏答案、重播慢放和独立记录，未复制项目代码、录音或课文。教学依据与边界见 [VOICE_DESIGN.md](./VOICE_DESIGN.md)。

## 服务端时限部署

`vite.config.ts` 声明 `VOICE_DEADLINES` Durable Object 绑定、`VoiceDeadline` 导出和 `voice-deadline-v1` SQLite 类迁移。托管发布必须保留此绑定和迁移；仅有 D1 不足以运行自动关闭。缺少绑定时状态接口显示未就绪，创建接口在任何收费请求前返回 503。部署后需确认实际绑定；本地构建通过不等于线上已配备该资源。

单活锁的租约时间 `until` 包含所选时长及一分钟启动余量；未确认关闭时，在 `until + 1 小时` 前禁止另开会话。这个截止时间也覆盖上游创建后 arm/直接关闭均失败、Worker 在登记闹钟前中断等孤立锁；状态接口会返回恢复截止时间。新记录设置有限过期时间，抢锁的原子条件按租约时间判断，已部署的 `MAX_SAFE_INTEGER` 过期记录也能在同一截止点回收，无需新增数据库迁移。终态后的记录恢复一天过期，不允许旧任务误释放新会话。

服务商关闭请求最多尝试 8 次，首次失败等待 15 秒，随后指数退避、最长 5 分钟；手动关闭与闹钟共用持久化次数和退避。网络、429 和 5xx 失败不会提前释放未确认的锁。次数耗尽会先清除凭据，保留无密钥的清理状态至上述恢复截止点；401/403、不可恢复的服务商拒绝、解密失败直接进入终态并清除凭据。数据库清理失败只重试无密钥的清理状态，也有退避和次数上限。终态恢复响应明确携带 `terminal: true, confirmed: false`，客户端可继续练习，但不会宣称上游已确认关闭。

这些恢复上限保证本机管理不会永久卡死，并不证明吊销密钥或控制接口故障后上游资源已终止；服务商账单需另行核对。轮换加密主密钥时仍应先结束会话，再移除旧解密密钥。

## 验证边界

单元测试覆盖 Responses 文本与流解析、转写分段、听写差异、取消后的迟到音轨清理、播放被浏览器拦截后的恢复、到时结束、会话归属、并发预算、关闭确认与超时。Worker 运行测试使用临时 D1 与测试密钥，不访问收费模型。

真实 OpenAI 模型权限、麦克风音质、iPad Safari 和付费音频端到端需配置真实 Key 后验证。云端浏览器没有可用设备朗读声音，已验证播放失败提示与未播放时禁止计分，不能视为声音播放成功。

## 2.7 学习体验

- 字幕显示/隐藏是浏览器内偏好，随时切换。隐藏期间不展示实时转写及开场题文本；转写仍供结束后的复盘使用，不等于停止转写。
- 开始前可以手动选择话题、难度、时长，或请求 AI 推荐，再选择应用。推荐不自动启动收费语音。自定义话题、目标和开场问题作为有界学习上下文传给服务端。
- 长期学习记忆与完整对话记录分开：前者保存在账号对应的 D1 记录中，可编辑、清空、暂停使用；后者仍保存在当前浏览器。记忆不会读取 ChatGPT 的历史或跨应用同步。
- AI 复盘产生的记忆只是候选，点击保存后才持久化；可手动记下偏好和待改表达。记忆关闭时，保存的条目和近期话题不进入推荐、复盘和 Live 的模型上下文。只有实际有发言的练习结束后才更新近期话题。
- 记忆 CRUD 无需模型密钥且不调用 AI。推荐与复盘复用已配置文字模型、服务端密钥和预算；模型输出严格校验，失败可重试或继续手动设置。
- 迁移 0006 新增账号隔离记忆表，不改变既有学习备份 schema、词条 ID 或复习调度。
