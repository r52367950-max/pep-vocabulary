# 词迹 2.19.0

本次将用户提供的 Claude AI 界面接入正式代码，形成对话、阅读帮助和练习行动的一组新增能力，并补齐账户隔离、取消请求和临时数据清理，采用次版本。交付为 PR；站点发布与合并单独进行。

## 界面与学习流程

采用提供的 Claude 原型（来源提交 `729fd80`）的对话排版、简洁模型菜单、历史侧栏、小窗与语音主区域。今日学习的山水插画、课程与进度、四项练习，以及现有词库、阅读和学习记录保留。

AI 对话在学习导航中独立进入；其他学习页通过圆形入口就地提问。完整页和小窗共用草稿、历史与引用。输入框主按钮在语音、发送和停止之间切换，输入法选词不会误发消息。对话偏好放在原有统一设置中。

阅读页的选文工具支持提问、翻译、词义和语法。引用保留原文位置与局部语境；全文和学习记录由来源开关控制。文本、PDF、DOCX 与图片复用现有本地提取模块，按实际读取状态提供文字给模型；图片在本次流程中用于文字识别。

模型返回的操作只能打开阅读或现有听写、复习流程；词条 ID 经发布词库核对。实际作答、重练及错项带回原对话，可继续分析。语音复用已有 WebRTC、服务端会话关闭与学习工具，进入同一完整对话区域；字幕与听写结果可接续文字交流。

## 请求与存储

新增 `POST /api/assistant/chat`，复用身份、同源、限流、出站配置、服务端加密密钥和原子预算。自动模式按任务选择 Sol / Medium、复杂规划 Sol / High、局部翻译与词义 Terra / Low、语法 Terra / Medium。界面保持自动、Sol、Terra 三个选择，实际模型和推理强度由服务端返回。已有自定义模型在 Auto 下沿用保存配置。

正常对话以账户范围保存有限文字历史；临时对话、原始附件、图片 URL 和选文原文不写入历史存储。异步发送、读取文件、跨标签页更新与本机清空沿用代际检查及写锁。数据格式与现有学习备份保持兼容，此次没有数据库迁移。

## 文案与性能

精简学习记忆、写作、识图、听写、练习反馈和设置中的重复说明。保留操作名称、真实来源和需要用户处理的错误。

- 对话及其样式按导航意图或打开动作加载，完成的消息行跳过草稿输入造成的无关重绘。
- 文件提取模块在选择附件时加载；备份工具在实际打开时加载。
- 折叠学习日志延迟渲染明细和编辑控件，展开后保留编辑草稿。

固定 30 天、90 条活动样本中，折叠日志的初始元素数从 668 降至 7，文本编辑框从 30 降至 0。该数值记录渲染工作量；实际命令和数据见 `artifacts/qa/claude-ai-20261109/learning-memory-performance.*`。
