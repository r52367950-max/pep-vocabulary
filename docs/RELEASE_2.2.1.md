## 新图标

原来的品牌有三套，互不统一：侧栏是红色"迹"字印章，浏览器图标是蓝色书本，主屏幕图标是绿底加麦克风。现在统一为一个图形：遗忘曲线的锯齿，每复习一次曲线就被抬回去一次，下面是一条蓝色底线，末端是一个蓝点。蓝色取应用主色 `#0071E3`。

| 位置 | 做法 |
| --- | --- |
| 浏览器标签页 | `public/favicon.svg` 内含深浅色两套配色，随系统外观自动切换：浅色为白底黑线，深色为黑底白线 |
| 侧栏与手机顶栏 | `BrandMark` 内联图形，跟随应用内的主题设置；iPad 竖屏只显示图形 |
| 主屏幕、PWA | `public/icons/app-192.png`、`app-512.png`，由 `icon-source.svg` 渲染。按可遮罩图标的要求铺满方块，图形位于 80% 安全圆内，圆角由系统裁切 |

图标换了新文件名：旧的 `icon-192.png` 和 `icon-512.png` 已删除，清单、`apple-touch-icon` 和 Service Worker 预缓存列表都已指向新文件。这样已安装的用户不会一直拿到缓存里的旧图标。

图形为本项目原创，方向和细节（去掉底色、底线变细、蓝色圆点）由项目所有者从多轮方案中选定。
