# 2.9.0：连续学习记录与对话听写

基于已发布的 2.8.1（Sites v36 / `4c539dc`）更新，保留已有安全修复、数据兼容与访问范围。

## 记忆方向

参考 ChatGPT 公开的[记忆说明](https://help.openai.com/en/articles/8590148-memory-in-chatgpt)：自动整理相关上下文、保留来源、允许纠正和删除。OpenAI 没有公开完整内部存储或检索架构，本实现是适合词迹的增量方案。

- 账户学习活动自动记录，按活动的 IANA 时区汇总每天学过的内容和进展，不再逐条确认。
- 词汇复习、阅读正文打开、文本 AI、写作批改、听写和口语复盘接入；学习条目保留来源 ID。阅读打开不冒充阅读完成，提示或纸上辅助练习不冒充独立掌握，一次错误不成为长期弱点。
- 云端保留活动与日摘要。口语摘要可包含简短学习目标/用户发言片段，不默认保存完整音频、照片或整篇作文。
- 所有 AI 模块通过统一上下文读取近期摘要和来源；与手工长期笔记、原始聊天分开。可编辑摘要、删除单项或整天、关闭自动记录/个性化；删除留下无正文的抑制标记，阻止旧事件重放。
- 普通追加只更新活动版本；隐私变更另行失效，避免自动记录打断进行中的 Live。

每天的记录由真实活动增量更新，无活动不虚构日报；没有另设网页关闭后的夜间模型作业。断网重试为当前页面内存队列，首次无法确认账户时不补记匿名活动，离页会丢失未同步队列。现有普通词卡 FSRS 继续保存；临时模式范围为 AI、口语、听写和写作。

## 对话听写与照片

普通 Live 对话后台固定为 `gpt-6.1-terra`，与通用文字模型设置分开。后台可以调用实际材料检索工具，按具体词语、教材册次/单元、正式阅读标题或近期记录准备听写；应用收到完整固定题单，Live 仅收到准备状态，不得到标准答案。找不到明确材料会追问。

听写入口自动准备推荐组，范围和错题收进“调整”。纸上作答可逐题听完后拍照，浏览器压缩图像再发送 Terra。识字请求不附标准答案，核对可编辑文字与题号后才由程序比较；模糊、未播题和重复题号不会被自动判错。照片不持久保存，取消/换题/切账户后拒绝迟到结果。

正式阅读库可由后端检索；原本仅在浏览器的私人导入全文不会被假称已在云端。显式提供的文章片段与正式来源分开标注。

## 界面与项目指引

阅读页将三个条件收进“筛选”，导入紧邻文章来源选择，保留筛选、分页与导入。根和 Apple Design 技能的 AGENTS.md 均压缩，CLAUDE.md 保留单一导入；依据当前 [GPT-6](https://developers.openai.com/api/docs/guides/latest-model) 与 [Opus 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5) 指南移除过时和重复约束，保留项目安全、数据与来源边界。

## 验证边界

自动化及浏览器测试使用模拟模型；没有消耗真实 Live、TTS、视觉或文本额度。真实通话往返、真实手写识字准确率与实体 iPad/Safari 尚未联调。具体测试数量与部署证据以本轮交付记录为准。
