# 词迹 2.2.0

本次为次版本更新：插画改为程序实时生成，新增三种记单词方式，并统一了图标、动效和无障碍细节。学习数据、词库和同步格式不变，无需迁移。

## 生成式插画

原来的 23 张 WebP 插画（共 540 KB）全部删除，改由 `lib/art/` 在 canvas 上实时绘制，脚本约 40 KB。同一篇文章每次打开都是同一张画，不同文章各不相同。方向在设计画布上确认后才落地，共做了六种风格样稿，最终采用三种。

| 位置 | 风格 | 变化方式 |
| --- | --- | --- |
| 今日学习 | 青绿山水 | 按本机时间切换清晨、白天、黄昏、夜晚，按日期换构图；卡片底色随天色变化，深色模式固定用夜景 |
| 阅读 · 散文与随笔 | 水墨江南 | 白墙黑瓦、柳丝、小舟和彩点，按文章 ID 生成 |
| 阅读 · 故事与小说 | 剪纸 | 马蒂斯式叶片、星与圆，四组配色 |
| 阅读 · 科学与世界 | 海流 | 噪声流场描出的洋流，三组配色 |
| 练习完成 | 植物标本 | 每轮练习一张 |

文章页顶部新增同款横幅。水墨与标本画中的红色"迹"字印章，也放到了侧栏和手机标题栏的"词迹"字样旁。

性能处理：
- 插画接近视口时才绘制，每个空闲时段只画一张，翻页和滚动不卡顿。
- 画好的结果以位图缓存，最多 48 张，回到同一页直接贴图。
- 胶片颗粒改为预先生成的贴图，由 GPU 叠加，不再逐像素读回。
- 在无 GPU 的无头浏览器中，单张 480×320 绘制约 10–70 ms（水墨最慢）。

## 记单词

今日页的"专项练习"改为"记单词"，入口有四个：词卡速记、配对消除、单元自测和单词听写。三种新方式的说明见下一节。它们都不改变复习计划；答错或标记"再看看"的词，可以一键转入原有的练习，由那里记录评分。

### 词卡速记

- 每组最多 20 张。先排没学过的词（按课本顺序），再排薄弱或到期的词，最后是其余。
- 翻面：点卡片、按空格或点"显示释义"。背面有词性、释义、一个例句（目标词加粗）和教材出处。
- 标记：右滑为"认识"，左滑为"再看看"。
  - 卡片跟随手指移动，并从按下的位置起算。
  - 松手时按速度预测落点，再决定飞出还是弹回。弹回用临界阻尼弹簧，从当前位置和速度接着动，中途可以再抓住反向。
  - 横向拖动超过 10px 才判定为滑动，所以不影响竖向滚动和轻点。
- 按钮和 ←/→ 键效果相同。撤销用按钮或 ⌘/Ctrl+Z。
- "再看看"的词在本组末尾再出现一次。完成页可以听发音，也可以把这些词直接转入练习。

### 配对消除

- 每轮最多 6 对，最多 3 轮。左列英文、右列中文，两列各自打乱。同一局里释义不会互相重叠。
- 配对正确：两块先锁定为绿色，再原地淡出，版面不重排。
- 配错：轻微抖动并记一次失误。"减少动态效果"开启时只闪红框。
- 计时每秒更新一次，标签页隐藏时暂停。每次配对结果都有读屏播报。
- 结束页显示用时、失误数和配错的词，可以把配错的词转入练习。

### 单元自测

- 题量可选 10、20 或全部（最多 40 题）。
- 混合四种题型：看英文选义、听音选义、拼写、语境选词。全程没有提示；"不会"算作答错并显示答案。
- 作答后立即显示对错和正确答案，按 Enter 进入下一题。
- 结果页有得分、逐题对错和答错词列表，可以把答错的词转入错词重练。
- 自测不改变复习计划。

## 图标

- 统一为 Phosphor 细线图标，去掉原来无底色的"图块"外框。
- 当前页的导航图标切换为实心，与 iOS 标签栏的习惯一致。
- 新增词卡、拼图、试卷三个图标。
- Lucide 操作图标的线宽改为 1.5/24，与 Phosphor 常规字重一致。
- 约 90 处装饰性图标加上 `aria-hidden`。

## 动效与材质

依据 Emil Kowalski 的 apple-design 动效技能（整理自 WWDC《Designing Fluid Interfaces》，本轮参考后未收入仓库，因与下文同名技能冲突）和 Web Interface Guidelines 调整：

| 交互 | 处理 |
| --- | --- |
| 按压 | 评分、选项、卡片、标签等按下即缩至 97%（100 ms），松开 240 ms 回弹 |
| 选中底板、练习进度 | 统一使用临界阻尼弹簧曲线（`linear()`，约 300 ms 到位），中途可改向 |
| 换题 | 新卡片从右侧 14px 淡入，提示前进方向 |
| 提示条 | 从下方弹入 |
| 词条详情 | 关闭时反向退出；手机上改为底部弹出的面板 |
| 手机标签栏、练习操作区 | 真正的半透明材质（72–78% 不透明 + 模糊），补 `-webkit-` 前缀，操作区上缘改为渐隐 |
| 插画 | 绘制完成后 480 ms 淡入 |

"减少动态效果"开启时，只保留淡入淡出和颜色变化，去掉位移、缩放和弹簧。原来会把颜色反馈也一并关掉，现已修正。另外新增两项系统设置的支持：
- "降低透明度"：半透明材质改为实色。
- "增强对比度"：加深分隔线和次要文字。

## 修复

- 21 个词条（如 a.m.）的开放例句数据是对象而不是句子，练习到这些词时原练习界面会崩溃。现在只读取字符串例句。
- 144 个词条的释义在抽取时丢了开头注释的左括号（如"源自拉丁语）上午"）。载入时补回；残缺更严重的数据保持原样。
- 练习中每答一题都会整屏闪出"正在准备词条…"。详情已预取时现在直接显示下一题。
- 揭示答案后焦点落到页面顶部，读屏软件也常漏读结果。现在焦点移到推荐的评分按钮，正误结果通过常驻播报区域读出。
- 词条详情：
  - 在备注框拖选文字、松手落在遮罩上时，会关闭并丢失未保存的备注。现在关闭时自动保存。
  - 关闭后焦点会回到原来的词。
  - 打开时背景不再滚动。
- 词库：
  - 选择模式下，点整行即可选中。
  - 清空搜索后焦点回到输入框，并回到第一页。
  - 补全列表和分组语义。
- 阅读：答题后按钮不再因禁用而丢失焦点；正文字号改用 rem，跟随系统字号。
- 使用提示后，评分说明会写明"这次最高记为「有些费力」"。
- 英文单词、题目和正文加 `translate="no"`，避免浏览器整页翻译把题目变成中文。
- 浏览器顶栏颜色跟随应用内的深浅色设置。清单中的 `theme_color` 改为白色。
- 以下改用等宽数字：练习计数、完成统计、记录图表、分页和教材进度。
- 12px 以下的阅读卡片文字提到 12px，并去掉中文字距。
- 提示条改为常驻播报区域，读屏软件能读到每一条。
- 从词库或词条发起的练习，标题改为"单词练习"（原来一律显示"今日学习"）。
- 搜索快捷键按系统显示 ⌘ K 或 Ctrl K。
- 后台标签页不再每分钟重算待学词，回到页面时立即更新。
- 数据载入后，空闲时预载练习和词条详情，第一次点开不用等待。

## 验证

在本仓库环境（Linux、无 GPU 的 Chromium）中完成：

- `npm run typecheck`、`npm run lint`：无错误、无警告。
- `npm run test:unit`：122 项全部通过，其中新增插画 6 项、记单词 15 项。
- `npm run data:audit`：状态 `release-candidate-with-declared-gaps`，与 2.1 相同，无新增硬错误。
- `npm run build`：生产构建和 Sites 产物校验通过。
- `npm run test:runtime`：Worker 路由、鉴权拒绝与数据库初始化用例通过。
- 在开发服务器上截图检查了以下界面：
  - 今日页：四个时段、深色模式，390、1440 两种宽度。
  - 阅读书架与文章页。
  - 三种新模式的入口页和作答页。
- 另一智能体用 Playwright 把三种模式从头到尾走了一遍，包括滑动回弹、快速甩出、方向键、撤销、深色模式与减少动态效果；未出现控制台错误或横向滚动。
