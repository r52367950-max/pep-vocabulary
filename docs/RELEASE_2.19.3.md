# 2.19.3：安全修复与对话反馈

同一 PR 更新周期内的安全、性能与交互修改合并为 2.19.3。保持现有学习功能、账户隔离和备份格式，按兼容性补丁发布。

## 安全与性能

- 发布包从已提交源码的独立目录构建，重新安装锁定依赖，拒绝额外私密文件和符号链接，逐项回读核对归档。
- 对话与听写共享教材来源校验；模型生成文字、个人文章及公开推理摘要保留来源边界。
- 自动学习日志仅保存活动统计。0010 迁移清理历史自动记录中的私人文本及派生摘要，保留用户主动编辑的标题和摘要，并使旧写入队列失效。
- 复用词库单元索引，限制搜索排序的中间集合。实测与正常结果对照见[安全报告](../artifacts/qa/security-20261110/report.html)。

## 对话体验

- 服务端发送实际思考、工具执行和回答校验阶段，界面显示等待文字与光标。
- 官方 OpenAI Responses 请求公开推理摘要，默认折叠展示；没有公开摘要时保留等待状态。
- 最终正文完成来源和账户上下文校验后渐进显示，保留完整字素；停止保留可见文字，刷新恢复最近保存的片段。
- 主界面与小窗上翻时暂停自动跟随，可回到最新。设置支持关闭渐进显示，并遵循系统减少动态效果。

## 验证与发布

完整 `npm test` 通过：700 项单元与集成测试、类型检查、ESLint、生产构建及产物校验、55 项真实本地 Worker/D1 回归。另有 19 项桌面与手机 Chromium 交互检查通过；浏览器使用可控流式测试响应，未调用付费模型或测试物理 iPad/Safari。详细结果见[对话报告](../artifacts/qa/chat-experience-20261110/report.html)及其[验证记录](../artifacts/qa/chat-experience-20261110/verification.json)。

线上身份可信域名已包含当前 `pep-vocab.namizore.chatgpt.site`，访问范围保持原配置。部署包包含 0000–0010 迁移、迁移 journal 和 Worker 入口；发布时核对实际迁移结果。两个报告保存验证时的快照，部署状态以对应 Sites 发布结果为准。
