# 词迹 2.16.0

2026-11-05，基于 main `3eb1875`，按现行代码重新整合 PR #18 中仍适用的修复。

- AI 缓存升级为 IndexedDB v2，结果写入与清除代次在同一事务中检查。全局清空等待缓存擦除，独立清缓存保留练习记录与画像授权；保留账号、学习日志作用域和活动记录。
- 同步 payload 限制为 1,900,000 UTF-8 字节，持久化文本合计不超过 1,950,000 字节；客户端预检、服务端 413。expectedIdentity 必填、revision CAS、旧快照读取和限流失败关闭保持。
- Live 自动关闭最多 8 次，15 秒起指数退避、最高 5 分钟，手动关闭共享计数。永久拒绝、解密失败或重试耗尽擦除关闭凭据并停止重试；未知上游状态保留非过期单活锁，管理员需核查服务商并确认终止后处理。确认关闭后先擦除凭据，再有界重试 D1 清理；旧会话清理不会释放新会话。终态返回 503，旧客户端也保持未确认状态。
- Next / eslint-config-next 16.4.3，sharp 0.35.5，source-map-js 1.2.2；Vinext 保持 0.0.50。新增生产依赖审计入口，并统一身份网关的部署说明。
- 阅读匹配按文本顺序扫描，达到 60 个匹配即停止，避免构造全文匹配中间数组；AI 缓存淘汰只读取索引键，不复制回答正文。

## 性能证据

以 2.15.0 为基线，4,681 个词条、60 篇文章匹配结果逐篇一致。240 次匹配、4 次预热、9 次采样中位数由 14.339 ms 降至 8.345 ms，减少 41.8%。这是同进程暖索引微基准，包含分词，不包含模型或网络延迟。可复测：`node --import ./tests/register.mjs scripts/benchmark-reading-lookup.mjs 3eb1875`。原始记录见 `artifacts/qa/2.16.0/reading-performance.json`。
