## 学习操作与账户数据

- 课本及字母排序可随时切换。随机队列在翻页和收藏时保持顺序，重新打乱时才生成新排列。新听写默认打乱，恢复练习时沿用已有题序。
- 右侧词条面板在切词、返回、关闭和进入练习前保存笔记。另一标签已改写相同字段时保留本页草稿并提示冲突。词条预取不会重置当前题的作答时间。
- 学习日志清单和助手上下文分别读取所需字段，保留用户手动修改的摘要、账户隔离和软删除规则。私有入口先核验身份，按输入限额读正文，限流存储异常时结束请求。
- 同源标签共享离线词库准备任务。公共静态资源按一致的缓存键写入与读取，下载完成后可断网刷新并打开词条详情。
- Next.js 使用 16.4.6，React、React DOM 与 RSC 使用 19.2.9。RSC 计入生产依赖，CI 审计包含构建工具。
