# 词迹 2.19.5

词库增加顺序选择，词条详情移到右侧，保留已发布 2.19.4 的修复。

- 默认按课本词表顺序展示；支持字母 A → Z、Z → A 和随机打乱。“再打乱”生成新的排列，翻页、搜索和收藏不会自行重新洗牌。
- 课本序号来自已发布来源记录的 `recordId`，按当前教材与单元取对应来源；必修一 Unit 1 从 teenage、teenager、ballet、volunteer、debate 开始。词条 ID、来源内容与分片均保留。
- 新听写轮次默认随机排列，恢复已有进度沿用保存的队列；语音工作区的整组单词听写同样随机，句子题单保持原顺序。
- 词条使用右侧非模态面板，桌面与平板为词表留出空间，小屏使用右侧抽屉。切词、关闭、返回与开始练习前保存笔记；保存失败保留编辑内容。AI 小窗在词条打开时暂时收起，关闭后恢复。

索引 `/2` 增加可选的并行 `sourceOrders` 列；旧客户端可忽略，新客户端继续接受旧缓存。没有新增依赖、迁移或付费调用。
