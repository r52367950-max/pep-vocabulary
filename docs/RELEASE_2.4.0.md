# 词迹 2.4.0

这是次版本更新：接回并扩展 AI 功能，新增写作与批改，细分错因，并改进性能、本机数据保留和密钥管理。词条 ID 与已有学习记录不变。学习备份 schema 升到 `1.2.0`，新增作文数据；旧的 `1.0.0` 和 `1.1.0` 备份仍可导入。过程、测试和未完成事项见 [2.4.0 更新报告](UPGRADE_REPORT_2.4.0.md)。

## 记单词

- **错在哪里**：学习记录按实际作答把最近 30 天的错误分成五类：拼写差一点、和别的词混了、拼写错误、想不起来、没听出来。每类可以一键重练。
- **容易混的词**：从你选错、写错成另一个词的记录里找出易混词对，可以一起练，也可以让 AI 辨析。
- **练习中造句**：熟悉的词答对后，可以选择用它造一个句子。本机检查目标词和长度，开启 AI 时还能检查语法和搭配。造句会记为一次“表达”练习，和其他作答一样与词卡在同一事务中保存。

## 写作

- 今日页“记单词”下方新增“写作”。系统推荐最近学过和答错的词作为目标词，你可以选择自由写作、应用文或读后续写。
- 写作时目标词用上就会打勾，本机同时检查篇幅、重复用词、长句、句首大写和代词 I 的大写，草稿自动保存。
- AI 批改给出估分、内容 / 词汇 / 语法 / 结构四项分数，把问题在原文中标号，并逐条给出改法。它还会评价每个目标词的用法，提出表达升级建议，给出修改稿和下次练习建议。
- 每次修改后再交会保存为新版本，并显示与上一版的分数对比。用错的目标词可以一键加入练习。
- 作文和批改保存在学习数据中，随 JSON 备份与手动云端快照一起保存。

## AI

- **词条详情**：
  - 讲解可选重点：综合、词义、语法、搭配、考点，以及答错过的词才有的“我的错误”。
  - 造句检查。
  - 记忆法：词根词缀拆分加联想。
  - 易混词辨析。
- **学习记录**：学习诊断与一周计划、针对错题出题（题目可以直接作答，不改变复习计划），以及用最近学的词生成的短文与理解题。
- **个性化**：请求附带由本机记录生成的学习画像，包括错误作答、错误类型、薄弱词、易混词、笔记和写作概况。教材信息仍然只来自服务端提供的词库证据。
- **输出上限**：统一为 10,000 token，模型上限更低时取模型上限。回答以流式读取，超时改为“无响应超时”，单次最长 5 分钟。
- **费用控制**：
  - 回答缓存在本机，重复查看不再请求。
  - 每日 token 预算默认 200,000，按北京时间日期计。
  - 可设置单次输出上限。
  - 设置页显示今日用量和缓存命中量。
  - 请求按“固定系统提示 → 学习画像 → 本次任务”排列，便于服务商前缀缓存命中。
- 新增提示词评测脚本 `scripts/ai-harness.mjs`，可离线检查提示词，也可选择真实调用。

## 性能与数据保留

- 作答保存不再复制整个事件数组，统计改为增量维护，今日页、学习记录和外壳共用一份结果。在 5 万条事件下，连续作答 200 次加统计的耗时从约 2.0 秒降到约 21 毫秒（Node 中测量）。
- 应用会向浏览器申请持久化存储，“数据与备份”显示是否受保护以及占用空间。未受保护且 14 天未导出时，最多每 14 天提醒一次导出备份。

## 安全

- AI 密钥支持分版本的主密钥与轮换，旧密文在使用或保存时自动改用当前主密钥；不设置新 Secret 时行为不变。
- 新增 `public/_headers`，给静态资源加基础安全头，并保留 `/assets/*` 的长期缓存规则。
- Service Worker 只接受同源页面的离线下载消息。
- 剩余使用 `^` 的依赖改为精确版本。

## 部署

- 执行 D1 迁移 `0003_small_smiling_tiger.sql`，新建 `ai_preferences` 表，只建表、可重复执行。未执行时 AI 仍可用，预算取默认值；保存预算时会提示先迁移。
- 密钥轮换是可选操作，步骤见 [AI 部署说明](../AI_ASSISTANT_DEPLOYMENT.md)。
- 页面升级到新的本机数据库版本前，需要关闭其他词迹页面。
