# 词迹 2.19.2

采用 Fable 后端交接包与 `claude/great-dirac-prol0i` 前端分支中适合现有词迹的改进。此版本在 2.19.1 的循环和界面上渐进完善，保持接口与数据兼容，升级补丁。

- **批量核词**：新增 `lookup_words`，最多八个词，保留教材词头和出处；区分精确匹配、括号简写及可能的屈折词形，后者提示结合语境核对。
- **教材筛选**：`search_lexicon` 支持教材代号、册名、单元、词头和中文释义；册与单元必须匹配同一来源，无效名称返回有限建议。
- **真实工具摘要**：回答与历史显示实际执行的“已查词库”“已计算”等摘要，失败明确显示未完成；仅保存已知工具名和布尔状态，最多六项。旧对话继续可读，临时对话不落盘。
- **对话面板**：修复全局搜索框 flex 与控件样式串入；收起时不渲染列表，输入当前草稿时复用已有列表结果。对话不足六条隐藏搜索，触屏展开时不自动弹出搜索键盘；采用 Fable 的学习者口吻建议。

当前三次模型请求、六次工具调用、原子预算、取消和轮间隐私校验继续生效。本轮无新增依赖或数据库迁移。

上传的 Python 子集存在已复现的 CPU／内存预算缺口，原生工具适配也尚缺完整的 Responses 推理项回放。本轮保留现有算术工具与 JSON 工具协议。具体证据和取舍见 [Fable 方案评估](FABLE_BACKEND_REVIEW.md)。

实测、检查结果和限制见 [单页报告 HTML](../artifacts/qa/fable-reference-20261110/report.html)、[PDF](../artifacts/qa/fable-reference-20261110/report.pdf) 与 [PNG](../artifacts/qa/fable-reference-20261110/report-page-1.png)。未进行收费模型调用。
