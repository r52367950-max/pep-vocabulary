## 兼容与迁移

新增 `0009_learning_journal_quota`，为既有日志回填事件数和计量用量，并维护后续原子额度。64 MiB 计量预算包含 UTF-8 文字、行开销及删除时间预留，用于限制应用分配。删除正文释放其文字额度，保留的事件 ID 继续计入行数，防止旧事件重放。

既有迁移、稳定词条 ID、学习备份 schema 和个人文章正文保持。现有超额账户保留读取和删除能力。站点部署沿用当前访问范围。

个人文章库内部升级至版本 3，保留原目录与正文；旧版本 2 客户端的后续写入会被阻止。已打开的旧页面需刷新以加载新版正文失效与导出保护；刷新前请保留尚未保存的输入。

## 版本规则

本次包含多项安全与 bug 修复，现有产品能力和兼容性保持，使用 `2.18.1`。后续成组新增功能并完成重大质量改进才升次版本；主版本留给明确的产品代际或不兼容公共契约变化，并提供迁移与回退安排。完整规则见 [开发与验证](DEVELOPMENT.md#版本分级)。
