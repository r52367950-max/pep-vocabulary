# 高中英语写作出题规则（简版）

## 选择与匹配
输入：题型、学生当前水平、已学主题与语法、目标篇幅、近期已练题目；输入缺失时以 B1 熟悉话题为保守默认，并注明估计。优先筛选题型，再按 CEFR（教学估计，非认证）、themes / unitKeywords 和 prerequisites 匹配；避免依赖尚未学过的关键语法或专业背景。按重复主题降权；匹配结果内随机选择。没有合适题目时解释放宽了哪些条件，或依规则原创。unitKeywords 为跨教材主题检索词，不能自动等同具体版次单元。

## 题目构造
- 自由写作：提供具体情境、清晰任务、读者或用途（适用时）和 2–3 个可执行要求；允许多种合理观点。
- 应用文：指定身份、收件人、目的和体裁，明确必要信息点与预期语气。无需虚构统计；要求报告数据时提供数据或要求写收集计划。
- 读后续写：原创完整阅读材料，人物、时间线、动机和视角自洽；提供冲突、可用细节、合理发展空间，以及两句能衔接且互不矛盾的段首句。要求围绕两句分别续写，保持人物与事件一致。该库的阅读材料约 150–220 词，续写 100–150 词（不含给定段首句），这是补学练习长度，不声称是正式试卷；正式考试以当地当年试卷说明为准。
- 建议篇幅 A2 50–80、B1 80–120、B2 120–180、C1 180–240 词；续写另用上列练习长度。随任务复杂度和学生实际能力调整，不用词数替代语言水平判断。
- 每题记录唯一 id、kind、title、prompt、cefr、wordMin、wordMax、themes、skills、prerequisites、unitKeywords、sourceIds、provenance；续写加 readingText 和两个 paragraphStarters。题目文本原创但沿用外部题型时标 adapted-pattern；全新任务表述标 original。标注来源用于溯源，不暗示官方背书或真题。

## 评价与反馈
按任务完成与内容、读者和交际目的、结构衔接、语言准确与表达范围四方面观察，描述具体证据。续写另检查段首衔接、原文情节与人称时态一致、情节发展及合理结尾。先肯定有效表达，指出最影响理解的 1–3 个问题，给可操作的修改建议和示例，再鼓励学生自行改写；区分必须修正的错误与可选润色。正式考试评分须使用对应地区、年份的官方标准，不能把本练习维度冒充官方量表。

## 质量检查
核实指令、语境和段首之间无矛盾；词数、难度与先修内容相称；阅读材料具备足够线索而非预设唯一答案；姓名与代词一致；对陌生文化背景提供足够信息；不用复述教材、真题或受版权保护文章长段。人工核验出处有效性和实际可读性后再上线。
