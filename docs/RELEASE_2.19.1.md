# 词迹 2.19.1

现有对话现在可按需调用学习工具，再依据工具结果回答。保持原有界面、模型配置、学习操作与备份格式，按渐进式后端完善、稳定性和性能修复发布补丁。

## 实际改动

- `lib/assistant/harness.ts`：独立的有界模型循环，最多 3 次模型请求、6 次工具执行，每批最多 3 项。普通回答一次返回；无自动付费重试。工具结果仅在本次请求内缓存。
- `lib/assistant/toolbox.ts`：正式词库检索、算术表达式、英文文本统计和所选文章/文件/引用读取。统计可直接指定来源，避免模型回写整篇原文。工具参数、结果长度、词条证据均由服务端校验。
- `/api/assistant/chat`：每轮经过现有身份、出站策略、token 预留及结算；继续生成前和返回前核对学习上下文。返回聚合用量及工具名、成功状态、缓存命中的简要轨迹。
- 附件：按服务端 UTF-16 上限截取，保留完整代理对，解决含 emoji 文件读取成功后请求超限的问题；避免大文本两次完整字符数组分配。

## 运行边界

工具箱采用 TypeScript，可直接运行于现有 Cloudflare Worker。计算器只解析有限算术语法；没有通用 Python、Shell、文件系统或外网执行能力。工具读取范围限于正式词库与本轮已选资料；临时对话、关闭记录及账户隔离沿用现有入口。开始复习和听写仍由用户点击按钮执行。

普通问答仍只调用一次模型，但工具说明会增加提示词长度；使用工具的任务可能调用两到三次。每日 token 预算逐次执行。本次未运行收费模型测试，真实服务商的质量、成本和端到端延迟待实际使用观察。

数据库 schema、迁移 0000–0009、稳定词条 ID 与备份格式保持兼容，无新增生产迁移。
