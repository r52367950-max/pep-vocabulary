# 词迹 2.1.1

本次为插画与版面的小版本更新，延续 2.1.0 的功能和学习数据。

- 散文、小说、科学各保留原封面并新增两张，共九张。各类保持燕麦、紫灰、淡绿底色，新场景增加适量彩色手绘元素。
- 用文章 ID 稳定选择共享封面；精选和个人导入文章沿用同一规则。筛选、翻页、重新打开不改变同一文章的封面，无需数据迁移。
- 今日计划加入透明背景的握笔与词卡插画。宽屏左右排布，窄屏把插画与标题并置，说明和操作保持整行宽度。
- 插画使用按尺寸选择的 WebP，阅读封面继续懒加载并保留分类底色后备。新增十四个尺寸资源共 234,618 字节，今日插画为 12,006 / 28,340 字节；不把七张原始 PNG 随网站发布。

## 视觉依据

依用户要求，由 Sol high 检索 Apple 官方实例，参考 [Today at Apple 地球主题漫画课程](https://www.apple.com/today/event/workshop-create-comics-inspired-planet-earth/) 和 [Apple Education 创意活动](https://education-static.apple.com/creativity-for-kids/activities.pdf) 的手绘轮廓、实色色块和单一动作构图。全部新图为原创生成，未随网站分发 Apple 图片或品牌资产。

完整生成提示词见 [ART_PROMPTS_2.1.1.md](ART_PROMPTS_2.1.1.md)。每张分类图独立生成；今日插画做过一次透明边距修正，随后等比例压缩，保留真实 alpha。
